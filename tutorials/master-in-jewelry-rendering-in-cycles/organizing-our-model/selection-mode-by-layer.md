# Selection Mode: By Layer

As we have seen before, it is possible to organize the elements and models on different layers, now we will see how to select objects inside those layers.

**Example 1:**

Based on four models organized by layers, we want to select the yellow model. To do this:

* We write in the command bar, SelLayer → Enter → Click on the layer we want to select → Press OK
