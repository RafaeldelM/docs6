# Exercise: Organizing our model

{% file src="../../../.gitbook/assets/Exercise1-Organizing-our-model.3dm" %}

In the file **Exercise1\_Render** we will find three models with different colors.![](https://academy.rhinoartisan.com/wp-content/uploads/2022/06/Ejercicio1_.png)

Using what we have learned, we must:

**1.** Group/Ungroup the different elements so that each color is a group.

**2.** Organize each element in layers created with the name of each color.

**3.** Give each layer the color of the element with the Mach option.
