# Transform: Copy

To copy an object we can:

Access the Transform tab → Copy → Copy on Object. This option follows the same mechanics as moving along a surface, except that it generates a copy of the selected element.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/image-1095-1024x626.jpg" alt="" height="489" width="800">

Select an element and press Alt + Drag any movement arrow.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/image-1098-1024x626.jpg" alt="" height="489" width="800">

Typing the command Copy → Select element → Enter → Select a point to copy from. To finish press Esq or **right click**.
