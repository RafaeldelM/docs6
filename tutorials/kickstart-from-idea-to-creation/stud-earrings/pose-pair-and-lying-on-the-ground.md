# Pose: Pair and Lying on the ground

### **Position the Model on the Plane**

Begin by going to the **Rendering** tab in the toolbar. locate and click on the **Lying on the Ground** command.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/Group-7221-1024x91.png" alt="" height="71" width="800">

This tool allows you to position elements on the selected axis and automatically calculates the necessary balance to position the element with the perfect inclination.

Click on the command and select all the elements of your earring model.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/image-1210.png" alt="" height="395" width="704">

In the command bar, ensure that the plane on which you want to position the earring is correctly selected.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/image-1211.png" alt="" height="64" width="339">

Once the plane is confirmed, press **Enter**.

Your model should now be perfectly positioned on the ground.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/image-1213-1024x557.png" alt="" height="435" width="800">

### **Create the Earring Pair**

In the **Rendering** tab, find and click on the **Pair** command to create a matching earring.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/Group-7221-2-1024x104.png" alt="" height="81" width="800">

Select all the elements of your earring model, just as you did in the previous step. Press **Enter**.

In the command bar, set a distance of **15 millimeters** between the pair.

For the pair's angle, type **-50 degrees**.

Mirror:  **No**

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/08/image-1214-1024x557.png" alt="" height="435" width="800">

Your model is now perfectly positioned and paired, ready for the next step.
