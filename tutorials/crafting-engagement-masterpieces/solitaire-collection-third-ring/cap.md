# Cap

### **Step 1**: Round Cap Command

Go to the **Solid** tab and use the **Round Cap** command to create a cap for the outer end of the shank.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/RoundCapCommand-1024x183.png" alt="" height="143" width="800">

Select the outer end as the curve and activate the **Flip** option. Set the height to **0.75 millimeters**.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/RoundCapCommandPanel-1024x503.png" alt="" height="393" width="800">

### **Step 2**:  Join

Select the cap and the rest of the shank, then type **Join** in the command bar or press the **Join button** to unite them into a single mesh.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Join-1024x503.png" alt="" height="393" width="800">

### **Step 4**: Cap Command

Select the shank and type **Cap** in the command bar to close the shank.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Cap_top-1024x410.png" alt="" height="320" width="800">

### **Step 5**:  Show the basket

Show the basket and the gem, by type show in the command prompt, or by click the outliner.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Cap_top-1-1024x358.png" alt="" height="280" width="800">
