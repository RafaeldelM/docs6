# Reference Curve and Gem Positioning

### **Step 1: Cueve Shank**&#x20;

In the **Shanks** tab, use the **Curve** command.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-2-300x111.png" alt="" height="111" width="300">

### **Step 2: Ring Size**

This time, select the **European size 54** for the reference curve.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-30-2-300x150.png" alt="" height="150" width="300">

### **Steps 3: Create the Gem**

Go to the **Diamonds** tab and use the **Gem Studio** command to create a **0.35-carat gem**. Change the alignment to **Culet**.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/GEm-0.35-3-1024x591.png" alt="" height="462" width="800">

### **Steps 4: Gems position**

Move the gem to the reference curve:

* Type **Move** in the command bar.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-32-1-300x89.png" alt="" height="89" width="300">

* With the osnap aids enabled, position the gem at the **top** of the reference curve.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Position-1024x353.png" alt="" height="276" width="800">

* Using the gumball, move the gem **1.7 millimeters upward** from the culet.
