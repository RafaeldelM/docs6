# Pose and Render

### **Step 1: Rotation**

In the right view, rotate the model 90 degrees using the gumball.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-10-3.png" alt="" height="469" width="479">

### **Step 2:  Rotate Comand**

Go to the "Transform" tab and select the "Rotate" command.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-11-3-1024x161.png" alt="" height="126" width="800">

### **Step 3: Pose**

From the Right view, select the lowest points of the model on both sides.

_See the two green points in the image_

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-12-2-1024x431.png" alt="" height="337" width="800">

### **Step 4: Align to plane**

Hold the Shift key to align the model with the axis.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-35-1-1024x386.png" alt="" height="302" width="800">

### **Step 5: Render**

Position the model using the gumball at the height of the X-axis. Set the parameters for the render and create the final image.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-33-1-1024x291.png" alt="" height="227" width="800">
