# Reference Curve and Gem Studio

### **Step 1:  Curve Command**

Go to the "Shanks" tab and select the "Curve" command.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-2-300x111.png" alt="" width="563">

### **Step 2:  Ring Size**

Set the region to "United States of America" and select size 7.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/image-1-2.png" alt="" height="129" width="491">

### **Step 3:**  Gems Studio

Switch to the "Diamonds" tab and use the "Gem Studio" command.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Gem-Studio-TOOLBAR-1024x141.png" alt="" height="110" width="800">

### **Step 4:  Add gem**

Select "Cushion" as the shape and set the size to 2 carats. Align the gem to the Culet, then press "Add."

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-1-1-155x300.png" alt="" width="563">
