# Curator: Save

1. Select the  **"Solitaire Collection"**.
2. Select the second completed model, then press **"Add".**
3. Give the model a name (e.g., **"Solitaire Model 2"**).
4. Once saved in the Curator, you can safely delete this model from the workspace if needed.
