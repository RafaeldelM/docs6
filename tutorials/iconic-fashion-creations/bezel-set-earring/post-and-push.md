# Post and Push

### **Step 1**: Curator Findings

In the **Curator** panel, go to the **Findings** category and select the **earring post push** component with a **5 mm** diameter.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Curator_post_push-1024x306.png" alt="" height="239" width="800">

### **Step 2**: Pose the Post and Push

In the **Top** view, using **wireframe mode**, type **Move** in the command bar. Move the post to the **center of the third gem** from the top.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/PostPush-1024x287.png" alt="" height="224" width="800">

### **Step 3**: Adjust the position

Switch to the **Right** view and adjust the post’s height to match the correct positioning.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Post_push_Pose-1024x287.png" alt="" height="224" width="800">
