# Pair

### **Step 1**: Pair Command

Go to the **Rendering** tab, select the entire model, and use the **Pair** command.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Pair_command-1024x110.png" alt="" height="86" width="800">

### **Step 2**: Set Parameters

Set the **angle** to **0** and the mode to **Mirror** in the command bar, then press **Enter** to create the mirrored earring.

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Pair_command_prompt-1024x319.png)
