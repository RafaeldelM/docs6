# Curves Pattern

### **Step 1**: Copy Command

Using the Copy command, copy the pair of **4.5 mm circles** to the center of the viewport.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/CopyTransform.png" alt="" height="139" width="800">

> Make sure to have **grid snap** enabled

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/CopyTransform00.png" alt="" width="563">

### **Step 2**: Move Circles

Now move the circles **-3.855** along the Y-axis. Use the gumball.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/CopyTransform-.png" alt="" width="563">

### **Step 3**: **PlaneHandle**

By using **Alt + PlaneHandle** ![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Handle.png) on the gumball to copy and arrange the circles.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Copyy.png" alt="" height="190" width="800">

### **Step 4:** Create this pattern

![](https://www.rhinoartisan.com/wp-content/uploads/2024/07/Pattern.png)

### **Step 5: Distance**

Ensure the outer curves **overlap**, and the **distance between points** is at least **1.5 millimeters** for stability.

* Go to the Analyse tab and use the Distance command to measure the distance between the two intersection points, as shown in the image.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Distance.png" alt="" height="269" width="800">

> For the distance to be correct, it should measure at least **1.5mm** to ensure the stability of the part.
