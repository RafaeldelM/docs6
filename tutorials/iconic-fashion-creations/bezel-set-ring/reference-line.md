# Reference Line

### **Step 1: Length**

Go to the **Analyze** tab and use the **Length** command to measure the length of the reference curve.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Analyze_lenght-1024x132.png" alt="" height="103" width="800">

### **Step 2: Curve** Length

In this case it is **75.067** millimeters.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Circle-Lenght-1024x190.png" alt="" height="148" width="800">

### **Step 3: Line From Mid Point**

In the **Curve** tab, under the **Line** submenu, select **Line From Mid Point**.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/MidPoint-1024x190.png" alt="" height="148" width="800">

### **Step 4: Create the Line**

From the **Top View** and with **Grid Snap** activated, select a center point below the elements.

Now, type the length of the curve followed by `/` and **2** to divide the measurement and create the correct line length.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Point-1024x190.png" alt="" height="148" width="800">

### **Step 5: Analyze**

Analyze this line to ensure it has the same length as the reference curve.

![](<../../../.gitbook/assets/Group 88.png>)
