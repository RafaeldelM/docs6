# Shank Profiles

### **Step 1: Edit the Shank**

Select the shank, then click on Edit and go to the 'Profiles' tab.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-18.png" alt="" height="582" width="547">

### **Step 2: Adjust the Profiles**

Adjust the first and second profiles.

* Change the curve to profile 002 for both.
* Keep the default parameters.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-21-1-1024x699.png" alt="" height="546" width="800">

### **Step 3:** For the third (bottom) profile

* Leave the curve unchanged but adjust the height to 1.7 millimeters.

<img src="https://www.rhinoartisan.com/wp-content/uploads/2024/07/Group-23-753x1024.png" alt="" width="375">
